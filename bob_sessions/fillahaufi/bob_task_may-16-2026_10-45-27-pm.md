### 🔍 Root Cause
The QR code library returns an `Illuminate\Support\HtmlString` object, not a plain string. When we tried to pass it directly to `base64_encode()`, PHP threw a type error because `base64_encode()` requires a string type.

```php
// Before (WRONG):
return 'data:image/png;base64,' . base64_encode($qrCode);

return 'data:image/png;base64,' . base64_encode((string) $qrCode);
```

Added explicit type casting `(string)` before passing to `base64_encode()`.
